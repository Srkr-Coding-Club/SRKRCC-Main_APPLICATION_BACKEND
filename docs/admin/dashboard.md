# Admin: Dashboard

## Purpose
The landing page after logging into the Admin Panel — a real-time snapshot of the whole platform's activity, so an Admin/Club Lead doesn't have to dig through individual modules just to know "how are we doing."

## What's On It

| Panel | Shows |
|---|---|
| Total Users | All registered accounts on the platform |
| Active Members | Members engaged recently (logged in / registered / submitted something) |
| Events | Count of events run/scheduled |
| Registrations | Total sign-ups across all modules |
| Registrations Overview (chart) | Trend line of registrations over time — spot spikes/drop-offs |
| Top Colleges (chart) | Breakdown of where participants come from |
| Recent Forms | The latest forms created via the [Dynamic Form Builder](form-builder-admin.md) |
| Upcoming Events | What's scheduled next, pulled from [Events](event-hackathon-management.md) and [Hackathons](event-hackathon-management.md) |
| Latest Registrations | Most recent sign-ups, live |

## Who Can See It
Admin (full dashboard); Club Lead (typically scoped to modules they manage — check with your Admin if a panel looks limited). See [../features/role-based-access.md](../features/role-based-access.md).

## What To Do From Here
- Notice a registration spike/drop → dig into that event/hackathon's own page.
- See a new form was created you didn't expect → check [Audit Logs](audit-logs-monitoring.md) to see who created it and why.
- Need the numbers offline (for a committee meeting, sponsor report) → use [Data Export](../features/data-export.md).
